# Contributing

Thanks for improving Codex Discord Presence.

1. Fork the repository and create a focused branch.
2. Keep the runtime dependency-free unless a dependency solves a substantial problem.
3. Run `npm run check` and the PowerShell/Python checks used by CI.
4. Do not commit transcripts, prompts, logs, IP addresses, private hostnames, tokens, or personal paths.
5. Explain the user-visible impact and validation in your pull request.

Bug reports should include Windows, Node.js, Discord, and ChatGPT/Codex versions plus the redacted `/health` response. Never attach a raw Codex transcript.
